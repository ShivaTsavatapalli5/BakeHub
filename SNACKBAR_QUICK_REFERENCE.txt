┌─────────────────────────────────────────────────────────────┐
│  💡 IMPORTANT TIPS                                          │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  1. Always pass BuildContext                                │
│     SnackBarService.showSuccess(context, ...);             │
│                                                             │
│  2. Check mounted in async callbacks                        │
│     if (mounted) { SnackBarService.show...; }              │
│                                                             │
│  3. Always hide loading snackbars                           │
│     SnackBarService.showLoading(...);                       │
│     await operation();                                      │
│     SnackBarService.hide(context); // Required!            │
│                                                             │
│  4. Use specific messages                                   │
│     ✓ "Chocolate Cake added successfully!"                 │
│     ✗ "Success!"                                            │
│                                                             │
